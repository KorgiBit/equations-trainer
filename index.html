Неизвестное слагаемое

Уравнения вида x + a = b.

РАЗБОР ПРИМЕРАx + 7 = 19
1

Определяем действие.

К неизвестному x прибавлено число 7.
2

Вычитаем 7 из обеих частей.

x + 7 − 7 = 19 − 7
3

Получаем ответ.

x = 12
Ответ: x = 12Проверка: 12 + 7 = 19 ✓
Правило: Чтобы найти неизвестное слагаемое, из суммы нужно вычесть известное слагаемое.

Уровень 2

Неизвестный множитель

Уравнения вида ax = b.

РАЗБОР ПРИМЕРА5x = 35
1

Разбираемся с записью.

5x означает 5 × x.
2

Делим обе части на 5.

5x : 5 = 35 : 5
3

Получаем ответ.

x = 7
Ответ: x = 7Проверка: 5 × 7 = 35 ✓
Правило: Чтобы найти неизвестный множитель, нужно произведение разделить на известный множитель.

Уровень 3

Два действия

Уравнения вида ax + b = c.

РАЗБОР ПРИМЕРА4x + 7 = 31
1

Вычитаем 7 из обеих частей.

4x + 7 − 7 = 31 − 7
2

Делим обе части на 4.

4x = 24 → x = 24 : 4
3

Получаем ответ.

x = 6
Ответ: x = 6Проверка: 4 × 6 + 7 = 31 ✓
Правило: Сначала вычитаем прибавленное число, затем делим на коэффициент перед x.

Уровень 4

Уравнения со скобками

Уравнения вида a(x + b) = c.

РАЗБОР ПРИМЕРА3(x + 5) = 36
1

Делим обе части на 3.

3(x + 5) : 3 = 36 : 3
2

Вычитаем 5 из обеих частей.

x + 5 = 12 → x + 5 − 5 = 12 − 5
3

Получаем ответ.

x = 7
Ответ: x = 7Проверка: 3 × (7 + 5) = 36 ✓
Правило: Сначала делим на число перед скобками, затем вычитаем число внутри скобок. Также можно раскрыть скобки.
